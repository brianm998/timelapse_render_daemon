# Stage s1295: desktop app shell (DSK-05)

Summary: DSK-05 gives the desktop app its shell of spec 2 §6.1 and §6.2: `--server`, the not-running screen with **Start trd**, the 2 s probe of the local server, the server switcher with pairing, the top bar, the menus, the Details pane's scan summary, and remembered server, window geometry, filters and Details pane. `AppState` holds one connection at a time; the Activity area is a placeholder until DSK-06.

Not verified here: the `kotlin-test` suite runs through the pipeline. The develop step could not resolve the pinned Compose version offline, so `:desktop` (main and tests) was compiled in a scratch copy against the cached Kotlin 2.1.0, Compose 1.7.3 and coroutines 1.9.0. The native menu bar, the real window and real service commands are not exercised by any test.
