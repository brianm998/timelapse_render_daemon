# Stage s1151: TRD-19 mDNS advertisement

Summary: trd advertises `_trd._tcp.local.` with the §8.4 instance name and TXT records, registers again when the LAN port or the IPv4 addresses change, withdraws on shutdown, and raises PROBLEM_MDNS_FAILED on errors; `--no-mdns` and `--lan-bind off` turn it off.
