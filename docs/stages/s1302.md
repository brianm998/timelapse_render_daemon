# Stage s1302: desktop Config window (DSK-08, task 1037)

Summary: **View → Config…** (Cmd/Ctrl+E) opens one window per server that edits the whole config and codec table (overview §6.4): a sidebar of the groups with issue counts, issues under their fields, a server folder browser for path lists, Save (Cmd/Ctrl+S) with the loaded revisions, Reload after a conflict, a save / discard / cancel question on close and on quit, and a refusal, with the server's message, to remove or rename a codec a variant uses.

`ConfigEditorUi` now also carries the config file's `path` and `rawJson`, for the Advanced group.

Tests: `ConfigWindowTest`, `CodecEditorTest` and `ConfigWindowsTest`, offscreen against `FakeTrdService`.
