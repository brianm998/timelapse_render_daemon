# s1313: race in DetailsPaneTest on the macOS desktop gate

`aRepeatedFailureAsksAgainAndAnotherChangeDoesNot` failed on `v3-gate/kotlin desktop (macos-15)`.
It waited for `callCount("GetRenderDetails") == 2` and then read the recorded requests.
`FakeTrdService` counts a call in its interceptor, before the handler records the request, so the
wait could end with only the first request recorded.

The test now waits for the second recorded request. The assertion on the failure ids is unchanged,
and so is the product code.

The cause was found by reading the code. The failure was not reproduced during development.
