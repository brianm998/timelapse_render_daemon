# s1146 — TRD-1187 t0-diff-check base on a node without origin/develop

Summary: t0-diff-check diffs against the merge-base of HEAD with origin/develop, then develop, and on a MASON node checkout against the newest ancestor of HEAD that two tasks' node refs carry; it fails loudly when no base is found, so the gate checks the whole change on any checkout.

- suite.sh: the base is the first merge-base that resolves; no HEAD^ or HEAD-only fallback. On a node checkout without either ref (marmot: no remotes, only refs/mason/node refs) the base is the newest first-parent ancestor of HEAD that node refs of two or more tasks contain. With no base it exits 1 and names origin/develop.
- test-scripts.sh: six cases (local develop passes; no base fails and names origin/develop; a whitespace error before HEAD fails the gate; on a node checkout a clean change passes, an earlier whitespace error fails, and one task's refs alone give no base).
- v3/1-trd-core-daemon.md §11: the t0-diff-check row describes the same base resolution.
- Decision record 1135.
- Still recommended: node marmot should fetch origin/develop into its checkout; that is an operational change outside this repository.
