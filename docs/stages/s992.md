Scope exception: `v3/scripts/check-makefiles.sh` skips a directory holding only `build/` only for `clients/kotlin` and `clients/kotlin/android`, because `suite.sh kotlin-test` and `android-test` write junit placeholders to `clients/kotlin/build/` when the Kotlin client is absent, which made the real-Makefile check fail after them in the shared test worktree; every other component directory without a Makefile still fails.
