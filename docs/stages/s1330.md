
## Task 1350: the engine's codec table reloads

The engine now owns a `CodecStore` (explicit `--codecs` file, else `video_codecs.json` beside the
config). Each tick it reloads on mtime change (a file that does not parse keeps the last good
table) and re-validates the config against the new table. `UpdateCodecs` pushes the new table
through `EngineHandle::set_codecs`, holding `config_switch` across the write and the push.
Switching the config path reopens the store for the new path.
