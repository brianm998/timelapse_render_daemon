# s1105 — TRD-17 gRPC server on loopback and `trd daemon`

Summary: `trd daemon` runs the engine and serves the §7 trd.v1 RPCs on loopback, with one thumbnailer shared by the engine and the server and streams that end with UNAVAILABLE on shutdown without stalling it.

What changed:
- `daemon.rs`: `trd daemon` assembles the store, config, codecs, tools and engine, binds loopback and prints `TRD_LISTENING`; SIGTERM/SIGINT end the streams and exit 0 without signalling any render.
- `server.rs`: every §7 RPC, with the snapshot and store rows mapped to proto messages. `WatchSnapshots` and `WatchLog` race each send against the shutdown watch; a stopped stream ends with UNAVAILABLE, the notice waiting at most one second so a client that does not read cannot hold shutdown.
- `trd-core/src/thumbs.rs`: `Thumbnailer` keeps its slot gate and runner behind `Arc` and offers `share()`. The daemon builds one thumbnailer and gives the engine a handle to it, so `MAX_CONCURRENT_THUMBNAILS` holds across both users.
- `trd-core/tests/thumbs.rs`: `thumbnail_share_caps_all_handles` checks the cap across two handles.
- `tests/server.rs`: thirteen tests against a daemon on port 0 with fake tools in temporary directories.
- The stop-signal handlers are installed before `TRD_LISTENING` is printed, so a signal sent right after the line stops the daemon cleanly.
- `WatchSnapshots` holds at most one unread message and reads the newest snapshot only when there is room for it, so a slow reader never gets a backlog.

Tests:
- `tests/server.rs` sits in `mod server`, so the A1 check `cargo test -p trd server` runs the whole file, and so do the unit tests in `src/server.rs` (`server::tests`).
- Added for the review: `ListDirectory` deadline through `within` with a zero limit (`server::tests`), `UpdateConfig` ERROR refusal and unparseable file, `UpdateCodecs` nameless codec, `sample_rate` clamping, `io_status`, `control_status` and `config_error_status` mappings, `roots`, `ListRenderedVideos` paging and search, and `GetServerInfo` under `--sandbox`.
- Slow reader: `watch_snapshots_gives_a_slow_reader_the_newest`. Signals: `stop_signals_are_installed_before_the_wait`, `signals_right_after_listening_exit_zero`. Log filters: `watch_log_filters_by_after_seq_and_level`.
- Page sizes: `rendered_videos_limit_defaults_and_caps`, `list_log_limit_defaults_and_caps`. Binding: `bind_retrying_retries_a_busy_port`, `bind_retrying_returns_none_when_stopped`. Name: `server_info_name_follows_advertise_name`.
