# Stage s1207: trd build and release workflows (TRD-27)

Summary: TRD-27 adds `v3-trd-build.yml`, which builds every trd package (macOS universal installer, Linux .deb and tarball for x64 and arm64, Windows installer and zip) from the ffmpeg and exiftool bundles of the same run, and `v3-release.yml`, which runs the version check, calls the ffmpeg, exiftool and trd workflows, and publishes a draft GitHub Release only on a `v3.*` tag push. `release-version.sh` holds the version and release logic and has its own test script, which `test-scripts.sh` runs.
